## Adapter notes / new-scraper plan

**This is NOT config-only.** No existing adapter parses a forward table embedded inside a single
Blogger post. Build a bespoke `SubicBayH3Adapter` (`src/adapters/html-scraper/subic-bay-hash.ts`),
register it, and route it in `registry.ts` / `htmlScrapersByUrl` on the blog URL.

**Fetch:** use `fetchBloggerPosts()` (`src/adapters/blogger-api.ts`) to pull recent posts (bypasses
cloud-IP 403). The forward feed only needs the **latest post whose title === "Hareline"**.

**Parse the Hareline table** (the post body is an HTML `<table>`; columns in order:
`Run# | Date | Hares | Venue | Att. | Total`). Per row:
- `runNumber` ← Run# cell (`Number.parseInt`, base 10). Skip the header row and any row with a
  non-numeric Run#.
- date ← Date cell `M/D` (**no year**) → infer year from the Hareline post's `publishOn` year, with a
  **Dec→Jan rollover** guard (if the row's month is much less than the post's month, it's next year).
  Store **UTC noon** (`new Date(Date.UTC(y, m-1, d, 12, 0, 0))`).
- `startTime` ← `"14:00"` (kennel default; not in the table).
- `hares` ← Hares cell; **split on `/` and `&`**, trim, `sort((a,b)=>a.localeCompare(b))`, join `", "`.
  Leave undefined when the cell is blank. (Sort is required for fingerprint idempotency.)
- `location` ← Venue cell; leave undefined when blank. Do NOT synthesize.
- `title` ← leave **undefined** (let `merge.ts` synthesize "Subic Bay H3 Trail #N"; shortName
  "Subic Bay H3" is >4 chars so `friendlyKennelName` short-circuits cleanly — verified length 12).
- `kennelTags: ["sbh3-ph"]`.
- Filter through `buildDateWindow(options?.days ?? 120)` — honor `options.days`.
- **Fail-loud guard:** if the parsed table yields **0 rows**, `errors.push("Subic Bay Hareline table
  empty — markup drift")` so `scrape.ts` suppresses stale-event reconciliation (a silent `events:[]`
  would never alert on a brand-new source whose baseline is already 0).

```ts
// src/adapters/html-scraper/subic-bay-hash.ts  (ILLUSTRATIVE)
export class SubicBayH3Adapter implements SourceAdapter {
  async fetch(source: Source, options?: ScrapeOptions): Promise<ScrapeResult> {
    const posts = await fetchBloggerPosts(BLOG_ID_OR_URL, { maxResults: 25 });
    const hareline = posts.find((p) => p.title.trim().toLowerCase() === "hareline"); // latest
    if (!hareline) return { events: [], errors: ["No Hareline post found"] };
    const rows = parseHarelineTable(hareline.content); // Cheerio over the post's <table>
    const year = new Date(hareline.published).getUTCFullYear();
    const events = rows
      .map((r) => buildEvent(r, year))               // year-infer + Dec→Jan rollover helper
      .filter((e): e is RawEventData => e !== null)
      .filter((e) => inWindow(e.date, options?.days ?? 120));
    const errors = rows.length === 0 ? ["Subic Bay Hareline table empty — markup drift"] : [];
    return { events, errors };
  }
}
```

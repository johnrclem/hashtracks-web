## Adapter notes / new-scraper plan

**NEW `src/adapters/html-scraper/laos-hash.ts` → `LaosHashAdapter`** (~160–220 LoC). Config-driven page→kennel
routing (mirrors the Bombay H3 "runs live in a WP page's content" pattern, but one current run per page and
three pages). **Reference adapters:** `bombay-hash.ts` (WP page content, `upcomingOnly`, no backfill, per-run
+ zero-row fail-loud), `hanoi-h3.ts` (single-current-run WP PAGE), `dublin-hash.ts`/`burlington-hash.ts` (field
cleaning). Model the class on `bombay-hash.ts`.

Control flow:
```
fetch(source, options):
  const days = options?.days ?? 120
  const events = []
  for (const p of config.pages):
    try:
      const json = await safeFetch(`https://hashlaos.com/wp-json/wp/v2/pages/${p.pageId}?_fields=content,modified`)
      const $ = cheerio.load(json.content.rendered)
      const text = $.root().text().replace(/\s+/g, " ").trim()   // collapses the FB-div soup
      const runNo   = p.hasRunNumber ? extractRunNumber(text) : undefined
      const date    = extractLaosDate(text)          // day+month, NO year → infer (Dec→Jan rollover), UTC noon
      if (!date) continue                            // block present but unparseable → skip this page
      const hares   = extractHares(text)             // "X is the Hare"/"hare is X"; "????"/"need a hare" → null
      const startTime = extractStartTime(text) ?? p.defaultStartTime
      const { location, locationUrl, latitude, longitude } = extractVenue($, text)  // Maps shortlink best-effort
      events.push({ kennelTags: [p.kennelCode], date, startTime,
                    runNumber: runNo, hares, location, locationUrl, latitude, longitude,
                    /* title left undefined → merge synthesizes */ })
    catch (e): errors.push(`page ${p.pageId} (${p.kennelCode}): ${e.message}`)
  if (events.length === 0) errors.push("Laos HHH: 0 events parsed across all pages")   // fail-loud → suppress reconcile
  return { events, errors }
```

Helpers (pre-extract to keep S3776 ≤ 15):
- `extractRunNumber`: `RUN_RE = /(?:run\s*#|hash[- ]?run\s*(?:no\.?)?\s*)(\d{1,5})/i` (use `RegExp.exec`).
- `extractLaosDate`: normalize `text.replaceAll("#", " ")`, then a **loose** day+month match
  `DATE_LIKE_RE = /\b(\d{1,2})(?:st|nd|rd|th)?\s*(?:of\s+)?([A-Za-z]{3,9})\b/` and validate the month word via
  `chronoParseDate`/a month map (avoid a 12-way alternation → S5843). Handles `"05 September"`, `"7th of
  September"`, `"27 September"`. **No year in source → infer** current year, rolling to next year if the
  inferred date is > ~30 days in the past (Dec→Jan). UTC noon (`Date.UTC(y, m-1, d, 12)`).
- `extractHares`: `HARE_RE = /hare\s*(?:is|:)?\s*([A-Za-z][^!.\n<]*)/i`; trim; if the capture matches
  `/^\s*(?:\?+|tbd|n\/?a|we need a hare|volunteer)/i` → `null` (explicit clear), if the label is absent → `undefined`.
- `extractStartTime`: `TIME_RE = /(\d{1,2})(?:[:.](\d{2}))?\s*(am|pm)/i` → "HH:MM"; **only** trust it when an
  am/pm is present (VH3's bare "A2A 5:30" has no am/pm and is really 17:30 → fall through to config default).
- `extractVenue`: pull the first `a[href*="maps.app.goo.gl"], a[href*="google.com/maps"]` as `locationUrl`;
  attempt to resolve a `maps.app.goo.gl` shortlink to coords (follow redirect via `safeFetch`, then
  `extractCoordsFromMapsUrl`); else leave lat/lng undefined (merge geocodes the venue text / Vientiane centroid).

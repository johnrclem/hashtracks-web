Parsing plan (single block → 0-or-1 event):
1. Select the "Next Run" caption: `$(".hero h3.caption")` (fallback: the `h3`/heading whose text starts
   with `Next Run`). **Fail-loud guard:** if that element is absent → `errors.push(...)` and return
   (suppresses reconcile on markup drift). *A block that parses but whose date is in the past is NOT an
   error* — emit the event and let `upcomingOnly` filter it.
2. `runNumber` ← `/#(\d+)/` on the caption text (`660`).
3. **Date (no year in source):** extract the `Month DDth` portion (strip the leading weekday word and the
   ordinal suffix), combine with an **inferred year** and store as **UTC noon**. Rule: use the current year;
   if the resulting date is more than ~30 days in the past, roll to **year + 1** (handles the Dec→Jan
   boundary). Prefer an explicit `Month Day` extraction over a bare `chronoParseDate` of the yearless string
   (chrono can pick the wrong side of "now"); if you do use `chronoParseDate`, pass a reference date and
   verify the result's weekday matches the parsed weekday word.
4. `startTime` ← `/(\d{1,2}):(\d{2})\s*([ap]m)/i` (`7:00pm`) → `"19:00"`.
5. `location` (venue) ← the **first** `<a>` text inside the caption (`The Snitterfield Arms`).
   `locationUrl` ← the `maps.app.goo.gl` `<a href>` (keep verbatim — it's a shortlink, **not** a lat/lng).
   Postcode ← the last `<a>` text (`CV37 0JH`) → drives geocoding downstream.
6. `title` ← **leave undefined** → `merge.ts` synthesizes "Warwick H3 Trail #N".
7. `hares` ← none in the block → leave undefined.
8. `kennelTags: ["warwick-h3"]`.

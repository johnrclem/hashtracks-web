## Adapter notes / shared-iCal-adapter enhancement plan

**This is ICAL_FEED but NOT pure config-only.** `src/adapters/ical/adapter.ts` (`ICalAdapter`, node-ical) exists and handles fetch/validate/date-window/run-number-from-description. What it does **not** handle for this feed (confirmed by reading the adapter):

1. **Colon-less SUMMARY → ugly title.** `parseICalSummary`'s title regex requires a `#…:`/`Prefix:` colon; Chichester's `"Old Faithful and Bambi  SU752074 Westbourne…"` has none, so `title` falls through to the whole SUMMARY. We want `title` undefined (merge synthesizes `"Chichester H3 Trail #N"`).
2. **Hares + venue packed in SUMMARY**, split by an OS grid ref token (`[A-Z]{2}\d{6}`, e.g. `SU752074`): hares = text before, venue = text after. No existing knob extracts this; `titleHarePattern` misfires on away/visit runs ("West London Hash Visit").
3. **Coords in `URL:https://maps.google.co.uk/maps?q=loc:LAT,LNG`** — `MAPS_URL_PATTERN` matches only `maps.google.com`, not `.co.uk`, so `resolveLocationUrl` never routes it; and the `0.000000,-0.000000` placeholders must be rejected.

**Recommended: a small, reusable enhancement to `ICalAdapter`** (~60–120 LoC incl. tests), gated by new opt-in `ICalSourceConfig` flags so no other feed changes behavior:
- `summaryGridRefVenue?: boolean` — when set, run a helper `splitSummaryOnGridRef(summary)` that finds the first `/\b[A-Z]{2}\d{6}\b/` token: hares = cleaned prefix (drop "???"/"& ???"/"Please volunteer"/"TBA" → undefined), venue = cleaned suffix; set `title = undefined` (let merge synthesize). Keep the helper a simple two-pass (find grid-ref index, slice) to stay under Sonar S3776/S5852.
- widen coord handling: either add `maps.google.co.uk` (and `maps.google.co.*`) to `MAPS_URL_PATTERN`, **or** add `parseLocUrlCoords?: boolean` that parses `?q=loc:LAT,LNG` from the `URL` property into coords, **rejecting `0,0`**.
- run number: already works via `runNumberPatterns: ["Run (\\d+)"]` (matches the DESCRIPTION `…trashRun NNNN…`) — no code needed.
- guard the malformed `DTSTART:20250307to10` multi-day special (non-ISO) — skip rather than throw.

**Alternative:** a thin dedicated `ChichesterHashAdapter` that fetches the `.ics` (reuse node-ical) and does the bespoke SUMMARY/coord parse. The shared-adapter enhancement is preferred — the SUMMARY+`loc:` format is produced by the `dupee.xyz`-backed calendar generator (`DESCRIPTION: …MAPS=https://dupee.xyz/maps.php?p=<gridref>`), so other South-Coast UK hashes may share it and benefit.

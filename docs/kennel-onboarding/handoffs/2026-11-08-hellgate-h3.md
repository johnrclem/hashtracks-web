```ts
export function parseHellgatePost(post: WordPressPost): RawEventData | null {
  const lines = htmlToLines(post.content);                  // <br>, </p> → \n; decode entities; NBSP → space
  const titleDate = parseTitleDatePrefix(post.title);       // only `^Mon Dth(-Dth)?, YYYY:`
  const dated = resolveDate(lines, titleDate, post.date);   // rule in "Live source verification"
  if (!dated) return null;                                  // warn, never throw
  return {
    date: dated.date,                                       // UTC noon convention
    endDate: dated.endDate,                                 // campouts only
    kennelTags: ["hellgate-h3"],
    title: stripTitleDatePrefix(post.title),
    hares: cleanHares(labelValue(lines, HARE_LABELS)),
    location: cleanPlaceholder(labelValue(lines, WHERE_LABELS)),
    startTime: dated.endDate ? undefined : pickStartTime(lines),
    cost: costIfNotDefault(labelValue(lines, ["Hash Cash"])),
    description: buildDescription(lines),
    sourceUrl: post.url,
  };
}
```

Parsing details:
- **`fetchWordPressPosts(url, 30)`**: the default of 10 can miss the current window once January's batch is posted. Publish order is not event order.
- **Multi-day:** a range in the title (`Aug 21-23, 2026:`) or a date line (`August 18th-20th`, `September 14 – September 16`,
  `Friday, July 18th – Sunday, July 20th`, `Campout Friday Aug 21st, … Depart Sunday Aug 23rd`) → `date` = first day, `endDate` = last day, no `startTime`.
- **Labels:** case-insensitive, optional hyphen and space: `Pre-lube`, `Prelube`, `Pre-Lube @`, `Chalk-talk`, `Chalk Talk`, `On-Out`, `On Out`, `Start Time`.
- **Time:** require a meridiem. `1:00 pm (updated time)` → 13:00; `Sat 10th @ 12:00pm` → 12:00 (don't read `10th`);
  `12:30 p.m.`; `2 pm`. `2:30ish` with no am/pm → skip it and use the next label, or leave undefined.
- **Placeholders → undefined:** `TBD`, `TBA`, `?`, `??`. `Vagina Mouth & TBD` → just the real name.
  A location such as `Double Front Cafe` stays; `Flippers. Buy your own beer pre lube` → trim at the first sentence (2025-11-08).
- **Description hygiene:** drop the `Future Hashes are mostly held…` footer, older `Future Hashes` schedule lists, and the labeled lines
  already mapped elsewhere. **Strip phone numbers** (`\b\d{3}[-.]\d{3}[-.]\d{4}\b`), e.g. the campout's "msg 406-…" line.
- **Cost:** first `$N` amount; emit the verbatim label value only if it isn't `$5`.
- **Guards:** `posts.length === 0` → push an error (a blank feed must not look like success). Any `fetchWordPressPosts` error → errors, no events.
- **Fixture:** use the real markup from `wp-json/wp/v2/posts`. Include one post per era: `Nov 21st, 2026` (`<strong>When:</strong> Sat, Nov 21, 2026<br />`),
  `Aug 21-23, 2026`, `Dec 18th, 2025: January Hash…`, `Mouth of a Schweatty Beaver’s Vagina` (`Date:`), `Hash of Hash Past Hash` (bare line),
  `The Tour de Wonder – Breaking Wind Hash` (value on next line).
- Window-sensitive tests need relative dates, or a mocked clock, so they don't age out.

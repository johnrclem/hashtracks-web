## Implementation gotchas (for Claude Code — repo knowledge, not source knowledge)
- **`config.upcomingOnly: true` required** (bounded-window blog fetch — see above).
- **Fail-loud zero-row guard** on this single-source adapter (`events.length === 0 && posts.length > 0`
  → push an `errors[]` entry so reconcile is suppressed; brand-new source has a 0 baseline so the
  zero-event health alert can't catch a silent parse break).
- **Sonar S5843/S5852 on date/month regex** — use a `Map`-based month lookup + a loose
  `\b\d{1,2}\s+\w+\b` (validate with the Map / `Date.UTC`), NOT a month-name alternation; strip
  ordinal suffixes with a plain `/(\d)(?:st|nd|rd|th)\b/` replace. Two-pass (find run line, then
  parse date) over a single combined regex.
- **Blogger body markup is Facebook-pasted** (nested `html-strong`/`html-span` spans, `&nbsp;`
  entities) → parse the `stripHtmlTags(content, "\n")` flattened text, never raw HTML.
- **Recaps duplicate run numbers** — only announcement posts become events; the merge pipeline
  additionally dedups same-`(kennel, date)` RawEvents, but don't ingest recaps as events.
- **`friendlyKennelName`** — shortName "Teign Valley H3" is >4 chars → synth "Teign Valley H3 Trail
  #N" is clean. (Do not shorten to "TVH3".)
- **Self-host tokenized Blogger logo** → `public/kennel-logos/tvh3.<ext>` (magic-byte the ext).
- **`Number.parseInt(s, 10)`**, `s.replaceAll(...)`, `Map.get()` over `obj[var]` (Codacy
  `detect-object-injection`), no negated ternaries (Sonar S3358).

## Implementation gotchas (for Claude Code — repo knowledge, not source knowledge)
- **`config.upcomingOnly: true` is REQUIRED** — a bounded recent-window fetch of a recap blog "ages out":
  a year later the same old posts fall outside the fetch window, so without `upcomingOnly` `reconcile.ts`
  would false-`CANCEL` the aged-off events. (Recap events are all past-dated, so `upcomingOnly` simply
  clamps reconcile to the future → it never cancels the archive. Same disposition as Devonport/TVH3.)
- **Fail-loud zero/per-post guard is MANDATORY** — single source, 0 baseline → the zero-event health
  alert can't fire. `if (posts.length > 0 && events.length === 0) errors.push(...)`, and push a `ParseError`
  for any `#NNNN` post whose date fails to parse (partial drift).
- **PII hygiene** — recap bodies contain participant hash-names and, in older non-run posts, real emails
  (`elly.maynard@hotmail.com` seen in the 2019 "Haberdashery" post). Leaving `description` undefined and
  skipping non-run posts avoids this; do NOT `JSON.stringify` a post into an error diagnostic.
- **Sonar S5852 / S5843 on the date regex** — normalize-then-`chronoParseDate`; no month-name alternation,
  no `\s*` adjacent to alternation. `extractHashRunNumber` keys on `#` (safe).
- **`Number.parseInt(s, 10)`** (not bare `parseInt`); `s.replaceAll(...)` (not `.replace(/../g)`) where no
  regex is needed; no negated ternaries.
- **Self-host the logo** into `public/kennel-logos/coeh3.<ext>`; confirm ext via magic bytes (GIF).
- **shortName "City of Exeter H3" (>4 chars)** → `friendlyKennelName` short-circuits to it directly; the
  synthesized title "City of Exeter H3 Trail #N" is clean. Verify once at build.
- **Backfill (if shipped)** — freeze JSON + dumb loader (commit the JSON, not the parser); require a
  leading `#NNNN` + parseable trailing date; run the frozen-dataset validation checklist.

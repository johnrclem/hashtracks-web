## Implementation gotchas (for Claude Code — repo knowledge, not source knowledge)
- **`config.upcomingOnly: true` is REQUIRED.** The adapter fetches the current-year file; at the
  year boundary it will fetch a new file and the prior year's runs vanish from the fetch → without
  `upcomingOnly`, `reconcile.ts` would false-`CANCEL` them. (The backfill owns all past runs.)
- **Same-date distinct-runNumber events** (#1145 + #1146 both 2026-12-06) — the merge fingerprint is
  `kennelTag + date + runNumber + title`, so distinct run numbers stay separate. Don't add a
  kennel+date-only dedup that would collapse them.
- **`0000` / `***CANCELLED***` / `tba` cells** — skip `0000`/blank run numbers; map `tba`/`***CANCELLED***`
  venue/hares to undefined (case-insensitive). Never emit numeric 0 as a run number.
- **HTTP-only source → Sonar S5332 hotspots.** Use `https` URLs in mocked tests (URL is a dead label
  there). Mark the 3 real production literals (kennel `website`, source `url`, adapter `DEFAULT_URL`)
  **SAFE** via the SonarCloud REST API (`POST api/hotspots/change_status`, `SONARQUBE_TOKEN` from the
  main-repo `.env`) with a justification.
- **NEVER pre-fill the logo extension.** Confirm via `curl -sI` Content-Type + magic bytes before
  self-hosting to `public/kennel-logos/quorn-h3.<ext>`.
- **Tests:** `vi.spyOn(globalThis,"fetch")` accumulates `.mock.calls` — add `beforeEach(vi.restoreAllMocks)`.
- **Sonar S3776 / S5852 / S5843** — keep parsing helpers extracted (`parseRunElement`, `cleanField`,
  `walkYearFiles`); avoid stacked `\s*`/alternation regex (the XML is well-structured, so most parsing

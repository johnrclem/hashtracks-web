## Implementation gotchas (for Claude Code — repo knowledge, not source knowledge)
- **Sub-letter split runs need `eventLabel`** (`1862A`/`1862B`, 70 in the archive). Without it, both rows
  collapse on `(sourceUrl, runNumber)` and merge's same-source date-correction deletes one real event. Mirror
  `parseRunLabel` in `mijas-hash.ts`; the date-correction probe co-matches on `eventLabel`.
- **`config.upcomingOnly: true` is REQUIRED** — `hareline.php` is a rolling forward list; old runs age off it
  every week. Without `upcomingOnly`, `reconcile.ts` false-`CANCEL`s the kennel's own past events.
- **2-digit-year pivot** — the archive spans `91`→`26`; a naive `20YY` misdates all 1991–1999 runs to
  2091–2099. Pivot `yy >= 50 ? 1900+yy : 2000+yy` (or anchor on run-number monotonicity). Also beware the
  `D MMM YY` chrono pitfall (handled by `chronoParseDate`'s `parseDmyAbbrevDate`, but strip the leading
  weekday first).
- **Do NOT harvest `maplink` as coords** — streetmap `?x=&y=` is British National Grid (easting/northing),
  not lat/lng. Emit no coords; merge geocodes the UK postcode / falls back to the Bedfordshire centroid.
- **Placeholder hares** — `"Hares Needed"` etc. are not names; null them. Strip run-type annotations glued
  into the hares field (`"Old King Cole 4pm BH Run"` → hares `"Old King Cole"`).
- **Self-host the logo** into `public/kennel-logos/h5-gb.<ext>`; confirm ext via magic bytes (don't hardcode `.png`).
- **Sonar:** keep date/label regexes simple (single `\s`, no stacked `\s*` around alternations); prefer
  `Number.parseInt(s, 10)`, `Map.get()` over `Record[var]`, no negated ternaries. Two-pass month parse
  (word-token + `Map` lookup) if a month-name map is needed — but a fixed `DD Mon YY` slice is simplest here.
- **Tests:** `beforeEach(vi.restoreAllMocks)` for accurate `fetch` call counts. Fixture = real `runData`

## Adapter notes / new-scraper plan

**🔴 This is NOT config-only.** Two hard blockers rule out the stock `GoogleSheetsAdapter`:
1. **Dates are British `D/M/YYYY`.** `GoogleSheetsAdapter.parseDate` assumes **month-first** for
   slash dates (`[month, day, year] = parts`). `20/09/2026` → month=20 → dropped; `5/3/2023` →
   silently swapped to May-3 instead of 3-May. Every day>12 row would vanish; every day≤12 row would
   be mis-dated.
2. **Run cells carry `#` / `FM#` prefixes and route two kennels.** `#1291` fails the adapter's
   `/^\d+$/` run-number test (so no run number extracted), and there is no run-#-prefix routing
   mechanism (`groupFilter` reads a dedicated *column*, which this sheet doesn't have). BH3 runs
   (`#N`) and BFMH3 runs (`FM#N`) must route to different kennelCodes.

**Plan — NEW bespoke `BucharestHashAdapter`** (`src/adapters/html-scraper/bucharest-hash.ts`;
`type: "HTML_SCRAPER"`, registered via `htmlScrapersByUrl` keyed on the sheet edit URL). Fetch the CSV
export `https://docs.google.com/spreadsheets/d/${sheetId}/export?format=csv&gid=${gid}` with
`safeFetch`, parse rows, emit `RawEventData[]`. **Model on** `src/adapters/google-sheets/adapter.ts`
(reuse its `parseCSV`) + `src/adapters/html-scraper/nswhhh.ts` / `dublin-hash.ts` for row cleaning.

Shape (illustrative — extract helpers to stay under Sonar S3776 ≤ 15):
```
fetch(source, options):
  csv = await safeFetch(exportUrl).text()          // anonymous CSV — confirmed 200 text/csv
  rows = parseCSV(csv)                              // reuse google-sheets/adapter parseCSV
  window = buildDateWindow(options?.days ?? 1600)   // honor options.days
  for row in rows:
    runCell = row[0]; dateCell = row[1]
    routed = routeKennel(runCell)                   // → {kennelTag, runNumber} | null
    if !routed: continue                            // header/blank/social rows
    date = parseDmy(dateCell)                        // D/M/Y + variants (see below)
    if !date or outside window: continue
    hares = clean(row[2]); location = clean(row[3]) // col 3 mixes trail-type/venue/theme — see gotcha
    startTime = parseTime(row[4]) ?? defaultTime(kennelTag, date)  // BH3→14:00, BFMH3→19:00
    emit { date (UTC-noon), kennelTags:[routed.kennelTag], runNumber:routed.runNumber,
           title: undefined,  // merge synthesizes; NEVER set title from theme/hares
           hares, location, locationUrl: mapsSearch(location),
           startTime, sourceUrl }
  if events.length === 0: errors.push("Bucharest sheet returned 0 rows — layout drift?")  // fail-loud zero guard
```

- **`routeKennel(runCell)`** — trim; `^FM\s*#?\s*(\d+)$` → `{ kennelTag: "bfmh3-ro", runNumber: N }`;
  `^#?\s*(\d+)$` → `{ kennelTag: "bh3-ro", runNumber: N }`; otherwise (empty / non-numeric social
  row) → `null` (skip). Keep the two regexes simple (single `\s`, no stacked quantifiers) to avoid
  Sonar S5852.
- **`parseDmy(cell)`** — the messy part; sample across the archive showed these variants:
  - plain: `26/2/2023`, `5/3/2023`, `1/12/24`, `30/01/26`, `28/08/2026` (D/M, 2- or 4-digit year)
  - dot separators: `23.10.2026`
  - trailing text: `18/05/2024 Hash Home Brew Fest`, `17/5/25 - Homebrew Fest`, `25/10/25 Halloween
    Hash`, `23.10.2026 (TBD)`
  - date **ranges** (away weekends): `25-27/10/2024 Transylvanian Hash` — take the **first** day.
  Recipe: strip everything after the first date token; normalize `.`→`/`; for a `D1-D2/M/Y` range keep
  `D1`; split on `/`; **day-first**; 2-digit year → 2000+; validate via `Date.UTC` round-trip; UTC-noon.
  **Do NOT reuse the stock `parseDate`** (month-first). Prefer explicit numeric parsing over a
  12-way month-name regex (Sonar S5843).
- **`defaultTime(kennelTag, date)`** — `bfmh3-ro` → `"19:00"`; `bh3-ro` → `"14:00"` (weekly Sunday;
  Saturday specials keep 14:00). Only used when the start-time cell is blank.
- **Column 3 gotcha** — "Trail type and location" mixes three things: trail type (`A-A`, `A-B`), a
  venue ("Grozavesti Metro station", "A-A Piata Sudului Metro"), and/or a theme ("Frankenstein Day",
  "Sturgeon Moon", "Ale Trail- Roofies Birthday!"). Simplest correct behavior: map the whole cell to
  `location` and geocode with Bucharest bias. **Never** promote it to `title` (leave title undefined →
  `merge.ts` synthesizes "Bucharest H3 Trail #N"). Optionally, if you want cleaner venues, route
  cells that don't look like a place (no metro/park/street/`A-A`/`A-B` token) to `description` instead
  — nice-to-have, not required.

**Registry:** add to `src/adapters/registry.ts` `htmlScrapersByUrl` an entry keyed on the sheet edit
URL → `new BucharestHashAdapter()`. (Or, if you route by a config discriminator instead of URL, mirror
the nearest existing sheet-consuming HTML adapter.)

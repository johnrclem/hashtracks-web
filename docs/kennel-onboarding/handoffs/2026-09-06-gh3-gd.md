## Adapter notes / new-scraper plan

**NEW `GrenadaHashAdapter`** — static self-hosted WordPress **schedule `<table>`** page.

- **Fetch:** `fetchHTMLPage("https://grenadahash.com/schedule/")` (from `@/adapters/utils`; static SSR,
  no browserRender). `DEFAULT_URL` = the schedule page.
- **Parse:** `cheerio.load(html)`, select the single content `<table>`, iterate `<tbody> <tr>`. Columns
  (0-indexed): `0=Date` ("29 Aug 2026", `DD Mon YYYY`, **year-bearing → no inference**), `1=Hash No`
  (int), `2=Hares`, `3=Location`, `4=Extra Info`.
- **Per row → `RawEventData`:**
  - `date`: parse `DD Mon YYYY` → **UTC noon** (`Date.UTC(y, m-1, d, 12)`). Use `chronoParseDate` from
    `@/adapters/utils` (year-bearing, unambiguous). Skip rows whose date cell is blank/unparseable.
  - `runNumber`: `Number.parseInt(col1, 10)`.
  - `startTime`: `"16:00"` (constant; table has no per-run time).
  - `hares`: split col2 on `&` and `,`, trim, drop empties, **sort** (`localeCompare`), `join(", ")`;
    blank → `undefined`.
  - `location`: col3, trimmed; `"TBA"` / blank → `undefined`.
  - `description`: col4 (Extra Info theme, e.g. "Halloween Hash") if non-empty; else `undefined`.
  - `title`: **leave `undefined`** → `merge.ts` synthesizes "Grenada H3 Trail #N". (Do NOT put the Extra
    Info theme or a hare name into `title`.)
  - `kennelTags: ["gh3-gd"]`.
  - coords: none from the table → let the kennel centroid (12.0561/-61.7488) be the fallback.
- **`upcomingOnly: true`** honored via `options.days` window; the rolling table ages out past rows.
- **Fail-loud zero-row guard (REQUIRED — single-page/single-table):** if the parsed rows array is empty
  (`rows.length === 0`), push an error and set `kennelPagesStopReason` so `scrape.ts` **suppresses
  stale-event reconciliation** and the failure surfaces (markup drift would otherwise "succeed" with
